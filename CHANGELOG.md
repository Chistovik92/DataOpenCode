# Changelog

Все значимые изменения проекта фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [2.0.0] — 2026-11-21

### Добавлено

- Перенос диалогов (сессий) во всех четырёх направлениях: V1 → V1, V1 → V2, V2 → V1, V2 → V2.
- Конвертеры JSON между схемами V1 и V2; исходный transfer JSON сохраняется в metadata импортированной сессии.
- Аддитивное слияние конфигурации: поддержка `provider` и `providers`, сохранение локальных конфликтующих значений.
- Пропуск существующих session ID; импорт родительских диалогов раньше дочерних.
- Флаги `-SkipSessions` (экспорт) и `-SessionDirectory` (импорт).

### Изменено

- Импорт больше не перезаписывает локальные значения: настройки, не связанные с провайдерами, сохраняются.
- Переменные окружения записываются только в область User (без Machine).
- V2 CLI запускается с `--standalone`, чтобы не подключаться к фоновому сервису с другим окружением.

### Безопасность

- Защита ZIP: path traversal, повторяющиеся пути, лимиты числа и размера элементов, контроль фактического размера.
- Отклонение повреждённых config/auth/env/session JSON до изменения конфигурации.
- Скрытие значений секретов и stderr CLI из вывода.
- Резервные копии с GUID перед изменением файлов и хранилища диалогов.
- Поддержка Unicode при экспорте диалогов.

## [1.0.0] — 2026-10-29

### Добавлено

- Первый релиз: перенос провайдеров и моделей OpenCode Desktop между компьютерами.
- Экспорт `opencode.json` / `opencode.jsonc`, `.opencode`, `auth.json` и переменных окружения.
- Импорт со слиянием конфигурации, понимание JSONC, резервные копии `*.bak`.
- Режимы секретов `-Secrets Auth/All/None`, флаг `-DryRun`, интерактивное меню.
